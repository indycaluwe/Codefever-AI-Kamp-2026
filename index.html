🚀 Dit arcade-portaal is ontworpen als een GitHub Pages website. Je kunt het eenvoudig zelf beheren, lokaal draaien en uitbreiden met nieuwe leerling-games!

💻 Hoe draai je dit portaal lokaal?

  1. Download de bestanden: Download de zip-map van GitHub of clone de repository naar je computer (of USB-stick).
  2. Open de pagina: Dubbelklik op index.html in de hoofdmap. Het portaal werkt 100% offline!

🎮 Games Toevoegen of Aanpassen

Er zijn twee manieren om spellen te beheren:

  • Optie A: Tijdelijk inladen via de browser (Lokaal)
    Klik bovenaan op 📂 SCAN GAMES DIRECTORY en selecteer je map met spellen. Gebruik daarna het potlood-icoon (✏️) op een kaart om speltitels of leerlingnamen aan te passen. Dit slaat op in de browser (localStorage).
  • Optie B: Permanent toevoegen via de code (GitHub)
    1. Plaats het nieuwe HTML-bestand van de leerling in de hoofdmap.
    2. Open index.html in een code-editor (zoals VS Code of Notepad++).
    3. Zoek naar de lijst genaamd const defaultGames (rond regel 1565).
    4. Voeg een nieuw spel-object toe aan de lijst, bijvoorbeeld:
    {
  author: "Naam Leerling",
  title: "Titel Van Game",
  category: "PLATFORM", // Kies uit: PLATFORM, PUZZEL, ACTIE of OVERIG
  description: "Korte samenvatting van het vette avontuur!",
  href: "naam_van_bestand.html"
}
    5. Sla het bestand op en push je wijzigingen naar GitHub om de website live te updaten!

🏷️ Optioneel: Scanner Metadata in Game plaatsen

Als je optie A gebruikt en wilt dat de scanner de gegevens direct goed herkent zonder dat je ze handmatig hoeft te bewerken, kunnen leerlingen deze commentaarcode helemaal bovenaan hun eigen HTML-bestand plakken:
